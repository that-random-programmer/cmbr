# cmbr: A Cambridge Pseudocode interpreter

`cmbr` is mainly a learning resource for students using Cambridge Pseudocode.

Note that this project is really new, and currently in alpha `0.1.0`

Right now, the basics have been implemented:

- if/else/else if
- case statements
- declarations
- assignments
- `INPUT`/`OUTPUT`

`cmbr` can stand for:

- an obvious abbreviation of "CaMBRidge", when it works
- Completely Maddening Bad Ragebait, when you want to be funny (who, me?) by referencing Linus Torvalds, and it doesn't work
